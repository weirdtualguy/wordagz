# paradox

**Language:** English (`en`) · **Part of speech:** noun

## Definition

An apparently self-contradictory statement, which can only be true if it is false, and vice versa.

!> **Semantic drift warning:** this definition shares no meaningful keywords with its root ancestor [παράδοξος](../../grc/c9/w-8add8de1.md) ("unexpected, strange").
